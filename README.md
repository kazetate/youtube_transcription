# YouTube Transcript Tools

YouTubeの動画ページ（タイトル直下）に「字幕ツール」パネルを追加するChrome拡張です。

- **字幕を取得**: 字幕を取得してプレビュー表示（複数言語がある場合は選択可）
- **コピー**: クリップボードにコピー
- **テキストでDL**: `動画タイトル.txt` として保存
- **タイムスタンプ**: `[1:23]` 形式の付与をON/OFF（設定は記憶されます）

## インストール

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択
4. YouTubeの動画ページを開く（開いていた場合はリロード）

## 補足

取得は、ページの字幕トラック → InnerTube API → YouTubeの「文字起こし」パネルのスクレイピング、の順に試します。字幕が無い動画では取得できません。
